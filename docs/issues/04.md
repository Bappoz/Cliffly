# 04 — Criar Studio com webcam, vídeo local e demonstração

Status: concluída na primeira versão

Issue pública: https://github.com/Bappoz/Cliffly/issues/4

## Objetivo

Interface acessível para transformar câmera ao vivo em blocos, com preview original e controles de qualidade.

## Critérios de aceite

- [x] Permissão de câmera somente após clique; desligar libera tracks.
- [x] Demo sem câmera e vídeo local sem upload automático.
- [x] Blocos renderizados com instancing, FPS real e limite de resolução.
- [x] Estados de permissão negada, câmera ausente e WebGL indisponível.
