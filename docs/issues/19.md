# Indicar cobertura e regiões que precisam de novas vistas

Status: implementada e validada.

Issue pública: https://github.com/Bappoz/Cliffly/issues/19

Validação: [CI aprovado](https://github.com/Bappoz/Cliffly/actions/runs/37877965042).

Acumular evidências por voxel, contando vistas distintas e diversidade angular. Diferenciar superfície observada com pouca evidência e com várias vistas. Orientar a captura para regiões visíveis com baixa cobertura.

Aceitação: Repetir o mesmo frame não aumenta cobertura; escala não muda a cada atualização; regiões vazias são desconhecidas, não declaradas como superfícies faltantes; testes geométricos de cobertura.
