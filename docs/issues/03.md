# 03 — Implementar núcleo de projeção de cores e profundidade em blocos

Status: concluída na primeira versão

Issue pública: https://github.com/Bappoz/Cliffly/issues/3

## Objetivo

Converter RGB e profundidade relativa em posições e cores, preservando a projeção da câmera.

## Critérios de aceite

- [x] Sem relevo baseado em brilho.
- [x] Projeção pinhole e orientação testadas.
- [x] Suavização temporal sem ghosting em movimentos grandes.
- [x] Formato JSON versionado com validação e export PLY.
