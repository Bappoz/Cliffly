# 02 — Tornar a ingestão de vídeo confiável e testável

Status: concluída na primeira versão

Issue pública: https://github.com/Bappoz/Cliffly/issues/2

## Objetivo

Substituir Task.Run solto por worker supervisionado, evitar uploads concorrentes e garantir manifests íntegros.

## Critérios de aceite

- [x] Upload vazio rejeitado; duplicado retorna 409.
- [x] Manifest atômico e recuperação de processing após reinício.
- [x] FFprobe valida stream de vídeo; processo cancelável e com timeout.
- [x] Testes de armazenamento, extração real e endpoints.
